# Local data directory

Place **user-provided local CSV files** under `data/local/`.

Collector-generated official candle datasets belong under `data/collected/`.

## Rules

- no automatic download
- no hidden exchange API calls from tests
- no large market data committed by default
- synthetic/test fixtures are **not** readiness evidence
- verify licensing and usage rights for any local dataset you place here

## Supported formats

- `GenericOhlcv`
- `BinanceKline`-like
- `UpbitCandle`-like
- `KrxOhlcv`-like
- custom column map through Sprint 17 onboarding config

## Expected format

The current examples assume Generic OHLCV CSV with columns such as:

`timestamp_ms,open,high,low,close,volume,trade_value,spread_bps`

Timestamp values are expected to be local CSV fields, typically millisecond timestamps in the current loader path.

## Minimum recommended rows

- preflight demo minimum: `40`
- real-evidence closure target remains conservative and depends on walk-forward/triple-barrier feasibility

## How to run preflight

```bash
cargo run --bin soma_experiment -- data-preflight --input data/local/BTCUSDT_1m.csv --out target/soma_data_onboarding --symbol BTC-USDT --timeframe 1m
```

## How to import a KRX daily market snapshot

If you can only save local **daily market snapshot** CSV files, first convert and store them as canonical per-symbol OHLCV:

```bash
cargo run --bin soma_experiment -- import-krx-snapshot --input data/local/data_3609_20260510.csv --out target/krx_snapshot_store --symbol 060310
```

This writes a stored file like:

- `target/krx_snapshot_store/060310_krx_1d.csv`

Then run preflight or onboarding against the generated per-symbol file.

## How to run onboarding

```bash
cargo run --bin soma_experiment -- onboard-data --config examples/soma_data_onboarding.toml
```

## How to collect official candle data locally

```bash
cargo run --bin soma_experiment -- collect-candles --provider upbit --symbol KRW-BTC --timeframe 1m --start 1711929600000 --end 1711953840000 --out data/collected
```

This writes raw archives, canonical CSV, provenance, manifest, and a preflight/rerun pack under `data/collected/<provider>/<symbol>/<timeframe>/`.

## How to rerun real evidence

```bash
cargo run --bin soma_experiment -- real-evidence --config target/soma_data_onboarding/generated_real_evidence_closure.toml
```

Use local files only. Remote URL-like paths are rejected.

`data/local/` stays user-provided. `data/collected/` is reserved for research-only official API local copies generated by Sprint 18 collector flow.
