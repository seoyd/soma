# KRX Downstream Rerun

Sprint 49 can feed validated KRX artifacts into conservative downstream reruns.

## Supported reruns

- official replication
- candle-pack generation through replication outputs
- official-evidence diversity sweep
- committee official benchmark
- core performance scorecard

## Conservative behavior

- skipped reruns are reason-coded
- sparse KRX rows do not imply usefulness
- outcome-link gaps remain blockers for stronger claims
- downstream summaries track before/after status without overclaiming

## Current usage

The shipped examples focus on local import, official replication, diversity sweep, and core performance diagnostics.
