# Control Tower Model Summary Cards

Sprint 67 upgrades the static Control Tower model ops view to **one summary card per model version**.

Each card can show:

- current conservative status
- risk level
- coverage and evidence completeness
- regression causes
- operator QA status
- next action
- Mamba runtime deferred state

The panel remains static and read-only. It does **not** add train buttons, live buttons, broker/order/account controls, or runtime Mamba behavior.
