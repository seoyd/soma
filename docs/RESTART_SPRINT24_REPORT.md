## Tests

## Warnings

This scalar CPU reference is intentionally small and bounded by the existing tiny-core memory limit. It is not an optimized Mamba-3 kernel and is not a proof of performance or official conformance.

## What Was Proven

The implemented Rust path is executable SISO recurrent math with explicit state and same-semantics sequence/streaming execution. It has no production Python or external-process dependency.

## What Remains Unproven

Official numerical parity awaits a vector fixture generated by the pinned upstream implementation. Training behavior, model quality, trading value, and performance relative to optimized official kernels are unproven.
