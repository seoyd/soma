# Deferred Modules

These modules are intentionally **not part of Soma Zero v0 runtime** in Sprint 02.

## Deferred model systems

- **Mamba3Fin** — deferred entirely
- **Sparse Mamba** (`soma-ssm`) — removed from the active repository
- **Gated DeltaNet / GDN** (`soma-gdn`) — removed from the active repository
- **FA3 / advanced attention work** (`soma-attn`) — removed from the active repository
- **MoR router** (`soma-mor`) — removed from the active repository
- **external memory systems** (`soma-memory`) — removed from the active repository

## Deferred adaptation / online systems

- **online learning** (`soma-online`) — removed from the active repository
- **adapter training / live adaptation** (`soma-adapt`) — removed from the active repository
- **training CLI / training skeleton** (`soma-train`) — deferred
- **closed-loop orchestration** (`soma-orchestrate`) — deferred
- **evolution sandbox** — deferred conceptually and not implemented here

## Deferred trading features

- real broker execution
- live self-mutation
- shadow promotion logic
- 6 / 12 / 18 investor league expansion
- leverage / short-selling execution / derivatives

## Deferred voice / narrative systems

- LLM persona voices
- news summarization
- narrative overlays
- any runtime generative reasoning

## Why deferred instead of removed

These modules are still relevant as historical or conceptual context, but they are no longer part of the active repository. `soma-zero` is the clean MVP kernel that remains in-tree.
