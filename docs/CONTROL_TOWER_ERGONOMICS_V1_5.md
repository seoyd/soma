# Control Tower Ergonomics v1.5

Sprint 60 keeps the current static Control Tower approach and improves readability around the existing paper-only state.

The ergonomics layer adds:

1. evidence warning badges
2. candidate cards with clearer status labels
3. copyable runbook command blocks
4. explicit Mamba deferred banner

The ergonomics output must still satisfy the same safety rules:

1. no execution buttons
2. no order/account controls
3. no browser command execution
4. local-only static output

`ControlTowerV1_5Ready` means the static dashboard is clearer for local monitoring. It does **not** mean production UI, cloud hosting, or live-trading controls.
