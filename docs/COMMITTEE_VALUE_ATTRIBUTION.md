# Committee Value Attribution

The Sprint 40 committee value report is a conservative proxy layer over committee-vs-baseline, committee-vs-no-trade, and optional committee-vs-external comparisons.

## Rules
- attribution is proxy-based unless true counterfactuals exist
- small samples stay diagnostic
- positive controlled evidence does not become official usefulness evidence
- dominance states (chair, persona, risk) are surfaced directly

## Typical use
Run the core performance scorecard first, then inspect `committee_value_attribution.txt` to see whether committee actions add value, mostly abstain, or are dominated by one layer.
