# Control Tower Model Trace Panel

Sprint 68 extends the static Control Tower model view with **trace links** per model version.

The panel includes:

- trace index coverage
- conflict / regression / QA / action summaries
- per-model local fragment links
- Mamba runtime deferred visibility

Fragments are static HTML only. The panel does **not** add train buttons, live buttons, POST actions, or broker/order/account controls.
