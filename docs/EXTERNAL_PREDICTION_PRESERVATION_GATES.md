# External Prediction Preservation Gates

Sprint 90 keeps four preservation gates visible:

1. schema preservation,
2. model-card preservation,
3. evaluation preservation,
4. runtime-deferred preservation.

Schema preservation covers sequence alignment, duplicate rejection, invalid probability rejection, and forbidden-column rejection. Model-card preservation keeps runtime, training, and live-inference states forbidden. Evaluation preservation stays offline-only, Trinity-only, and research-only.
