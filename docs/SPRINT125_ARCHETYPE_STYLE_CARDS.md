# Sprint 125 Archetype Style Cards

Sprint 125 adds safe public-philosophy-inspired archetype style cards for the existing three-member pilot.

- The 18 archetypes are style references only, not live AI members.
- Cards must state they are not real person clones and must include do-not-learn guards for private details, exact personality cloning, unsupported profit claims, unsourced quotes, and illegal/private information.
- Review-required or low-confidence cards stay review-labeled and receive limited deterministic style weight.
- The style mapping injects lightweight influence into `TrendEntryAI`, `RiskGuardAI`, and `EvidenceRegimeAI` only.
- Style influence can adjust deterministic/mock confidence notes, but it cannot override Risk Governor or create broker/order/account paths.
- No real Mamba3 runtime, Gated DeltaNet runtime, model training, live inference, runtime LLM debate, live trading, or 18-agent activation is added.
