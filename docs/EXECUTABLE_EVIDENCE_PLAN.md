# Executable evidence plan

Sprint 31 turns provider reality into bounded executable evidence lanes.

## Inputs

- `ProviderRealityReport` JSON generated by `provider-reality`, or
- explicit lane definitions in an evidence-plan TOML

## What the plan does

- maps providers into lane kinds
- marks lanes as runnable or skipped
- preserves provider freshness and entitlement semantics
- enforces max lane, symbol, row, request, and byte budgets

## Conservative rules

- missing auth becomes a skipped lane
- missing approval becomes a skipped lane
- missing endpoint template becomes a skipped lane
- EOD data cannot become a realtime lane
- yfinance can only become `YFinanceResearchFallback`

## Typical flow

```bash
cargo run --bin soma_experiment -- provider-reality --config examples/soma_provider_reality.toml
cargo run --bin soma_experiment -- evidence-plan --config examples/soma_evidence_plan_crypto_only.toml
```
