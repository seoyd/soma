# Control Tower Briefing Panel

The Sprint 71 Control Tower briefing panel is a one-screen static summary.

## Panel contents

- primary headline and overall severity
- section summaries
- owner attention summary
- model attention summary
- evidence attention summary
- deferred summary
- next command blocks
- links to static fragments

## Severity

- `Good`
- `Watch`
- `NeedsAction`
- `Blocked`
- `Deferred`

## Fragments

- `owner_review_briefing.html`
- `next_actions.html`
- `model_attention.html`
- `deferred_items.html`

## Safety

The panel has **no execution controls**, **no POST/actions**, and **no live/order/account buttons**. It is a static local briefing surface only.
