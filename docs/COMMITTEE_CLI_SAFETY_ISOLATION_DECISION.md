# CommitteeCliSafety isolation decision

CommitteeCliSafety can remain a permanent isolated sentinel when grouped suites already represent the broad safety guarantees and the isolated test still protects the highest-risk committee-specific command surface.

Unsafe merge blocks queue advancement. Explicit isolated-sentinel treatment is acceptable only when remote path rejection, help text, forbidden commands, runtime-deferred semantics, persona guards, order/account guards, browser guards, and deterministic CLI surface checks remain represented elsewhere.
