# KIS Control Tower Monitor

The KIS monitor panel summarizes local market-data readiness only.

## Covered state
- auth readiness
- redacted base URL readiness
- endpoint policy status (market-data-only)
- collection dry-run / local-import readiness
- candle sufficiency
- outcome-link closure
- evidence diversity / bottleneck
- exact next KIS commands

## Safety
KIS remains market-data-only. No broker, order, account, balance, holdings, position, buying-power, or execution endpoints are surfaced.
