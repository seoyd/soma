# Sequence Core External Prototype Contract

Sprint 79 defines an **external prototype contract** for sequence-core candidate comparison.

It supports:

- `Mamba3Fin`
- `GatedDeltaNet`

And it limits execution to:

- prediction CSV only
- external research only

It forbids:

- Rust runtime inference
- Rust training
- live inference
- broker execution
- online learning
- runtime LLM decisions
