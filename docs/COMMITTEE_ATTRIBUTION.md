# Committee Attribution

`CommitteeAttributionReport` provides proxy attribution for the committee pipeline.

## What it measures

- persona vote counts
- selected-speaker counts
- average voice power and conviction
- decision-influence proxy share
- Chair contribution summary
- Risk Governor contribution summary
- source contribution summary

## Warnings

- Small samples return `InsufficientSamples`.
- Strong concentration emits overdominance warnings.
- Never-selected personas emit underparticipation warnings.

## Interpretation

This is operational telemetry for the committee architecture. It is not a claim that any real investor or discretionary committee has been reproduced.
