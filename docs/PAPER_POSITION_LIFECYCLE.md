# Paper Position Lifecycle

Sprint 56 adds simulated paper lifecycle reporting.

## Supported events

- PaperOpen
- PaperUpdate
- PaperTargetHit
- PaperStopHit
- PaperExpired
- PaperRiskClosed
- PaperManualReviewed
- PaperClosed

## Boundaries

- simulated only
- no broker account linkage
- no actual holdings
- no real order ids

Paper lifecycle reports summarize deterministic paper-state outcomes for monitoring and audit.
