# Regression Evidence Trace

Sprint 68 links regression explanations to **baseline/current evidence** when local snapshots are available.

It can trace:

- coverage regression
- calibration regression
- risk regression
- comparability regression
- artifact completeness regression
- leaderboard regression

Interpretation stays limited: the trace helps explain why a model stayed conservative, but it does **not** prove failure is permanent, deployability, or profitability.
