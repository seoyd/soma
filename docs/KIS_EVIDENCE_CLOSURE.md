# KIS Evidence Closure

Sprint 61 adds a bounded local-only closure layer for the Sprint 60 evidence gap.

- `kis-evidence-expansion-plan-v2` builds a small evidence plan with symbol / timeframe / horizon bounds.
- `kis-evidence-closure` combines the bounded plan, prior evidence-hardening output, outcome-link depth, owner discipline, and sequence readiness into one deterministic bundle.

The example configs live in:

- `examples/soma_kis_evidence_expansion_plan_v2.toml`
- `examples/soma_kis_evidence_closure.toml`

The generated artifacts stay under `target/sprint61` and remain research-only, paper-only, local-only, and read-only.
