# Workspace Safety Guard Suite

`tests/workspace_safety_guard_suite.rs` keeps safety coverage first-class.

It preserves checks for:

- no live trading mode
- no broker/order/account execution path
- no runtime LLM path
- no Mamba or Gated DeltaNet runtime activation
- no browser execution controls
- Control Tower UI safety readiness
- dashboard serve deferral
- static HTML/JSON/TXT first UI framework choice
