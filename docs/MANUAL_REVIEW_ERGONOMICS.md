# Manual Review Ergonomics

Sprint 60 improves how the owner review queue is explained, not how it executes. The goal is to make paper-only review states easier to understand without adding browser actions or broker-side effects.

The ergonomics report highlights:

1. pending review count
2. risk-blocked count
3. paper-confirm allowed vs blocked counts
4. missing reason-code coverage
5. unclear action surfaces

The associated workflow report stays explicit about paper-only review. It can list **copyable commands** and ordered review actions, but it does not execute anything and cannot weaken Risk Governor.
