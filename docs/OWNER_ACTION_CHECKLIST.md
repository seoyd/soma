# Owner Action Checklist

The Sprint 71 owner action checklist is a **paper-only, copy-only** review surface.

## Safe owner actions

- review model disposition
- review leaderboard warning handling
- review retirement evidence
- request more offline predictions
- keep a version diagnostic-only
- defer review

## Forbidden actions

- live promotion
- runtime enablement
- model training
- broker, order, or account actions

## Command flow

Checklist command suggestions are local `cargo run --quiet --bin soma_experiment -- ...` commands only. They are meant to be copied into a terminal, not executed from the browser or from the static HTML briefing.
