# Official Committee Benchmark

Sprint 36 layers an official, outcome-linked benchmark on top of the Sprint 35 committee benchmark flow.

## Flow

1. build/load an `OfficialCommitteeScenarioPack`
2. link outcomes, baseline actions, and optional external predictions
3. run core-check
4. run committee benchmark
5. build outcome-linked comparison
6. build official readiness interpretation
7. write the official benchmark bundle

## Comparison surfaces

- committee final action
- baseline action
- no-trade baseline
- risk-denied counterfactual value proxy
- optional external prediction action

## Readiness

- research-only rows cannot pass official readiness
- fixture rows cannot pass official readiness
- crypto-only evidence remains crypto-only
- summary-derived dominance blocks readiness
- no-lookahead violations block readiness
