# Mamba3Fin Artifact Family

Sprint 64 tracks the **Mamba3Fin-lite external artifact family** as model cards, prediction CSVs, evaluation artifacts, promotion artifacts, and a contract artifact.

Important distinction:

- `ContractReady` means the offline artifact family is documented and comparable
- it does **not** mean a Mamba runtime exists
- it does **not** add Rust-native inference or training
- it does **not** add live inference or broker wiring

Runtime Mamba remains explicitly deferred. Sprint 64 only tracks artifact lineage and registry visibility.
