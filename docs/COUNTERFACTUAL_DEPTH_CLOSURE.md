# Counterfactual Depth Closure

The closure runner compares previous and current comparable evidence after optional rebuild steps.

It records:
- previous/current comparable counts
- added complete rows
- added outcome, baseline, NoTrade, and RiskDenied references
- added official comparable rows
- scorecard bottleneck movement after rerun

Interpretation stays conservative: controlled-only, crypto-only, and research-only improvements never become official readiness.
