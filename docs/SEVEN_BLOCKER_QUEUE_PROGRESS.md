# Seven Blocker Queue Progress

`SevenBlockerQueueProgressReportV5` tracks whether the primary blocker remains `CandleExpansionOps` or advances to `ExternalPrediction`. Queue advancement is only valid when candle reduction evidence is explicit and safety coverage stays preserved.

`RemainingBlockerQueueV5` then materializes the ordered remaining families and the primary next family used by the read-only Control Tower candle recovery panel.
