# Source-bound learned-agent opinion V1

V1 is a new retrospective-only protocol. It does not migrate, repair, or
replace V0 opinions, seals, transcripts, ledgers, or provenance conclusions.

Before any historical replay, the registration manifest fixes exact source
result, raw scope, effective-anchor scope, forecast scope, model-artifact,
two-round, seal-before-reveal, legacy-preservation, and no-authority rules.
The registration digest uses explicit canonical bytes and excludes paths,
timestamps, terminal output, and debug formatting.

Every V1 seal binds the registration digest, exact source result digest, raw
scope digest, anchor scope digest, forecast scope digest, and an authority
digest. V1 is labelled as historical retrospective replay, never prospective
or contemporaneous evidence.
