# Scenario Materialization Weak Closure

`ScenarioMaterializationWeak` means the evidence set still leans too heavily on summary-derived rows.

The closure report measures:
- row-level ratio before/after
- summary-derived ratio before/after
- comparable and complete row counts before/after
- official-complete row counts before/after
- remaining materialization gaps

Improvement requires more row-level evidence and less summary-derived dependence.
