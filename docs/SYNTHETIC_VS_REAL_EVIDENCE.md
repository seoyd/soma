# Synthetic vs Real Evidence

Synthetic and test fixtures are still valuable, but only for the right purpose.

## Synthetic/test use

- deterministic smoke coverage
- backtest pipeline verification
- conservative safety testing

## What they do **not** prove

- market edge
- live robustness
- readiness for broader persona scope
- real-money safety

## Sprint 16 interpretation

If synthetic evidence looks strong while real evidence is missing or weak, the report stays conservative and recommends more data, better data, or stronger signal validation instead of expansion.
