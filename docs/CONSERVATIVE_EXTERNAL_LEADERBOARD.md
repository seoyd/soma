# Conservative External Leaderboard

Sprint 64 adds a **conservative offline leaderboard** for comparable external artifact versions.

Ranking is penalized by:

- weak coverage
- poor calibration
- weak risk-adjusted score
- unstable ablation results
- small sample size

The leaderboard also keeps these references visible:

- baseline
- Trinity
- NoTrade
- RiskDenied

This leaderboard is **not** a deployment signal. Rank 1 still means offline research only. It does **not** allow live promotion, live inference, broker execution, or real-money use.
