# Committee performance evidence matrix

The performance matrix compares committee outcomes against:
- baseline actions,
- a NoTrade proxy,
- RiskDenied defensive value,
- optional external predictions.

Evidence strength levels:
- `StrongOfficial` / `ModerateOfficial` for readiness-eligible local evidence,
- `CryptoOnly`, `ResearchOnly`, `FixtureOnly` for constrained evidence,
- `DiagnosticOnly` for estimated or otherwise blocked comparisons,
- `Insufficient` when outcome evidence is missing.

Passing this matrix does not prove profitability and does not authorize live trading.
