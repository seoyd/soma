# Workspace Timeout Track Execution

The runner imports Sprint 115 truth, activates the timeout track, builds the observation backlog and burn-down plan, emits diagnostic-only observation reports, and writes a deterministic bundle under `target/soma_sprint116_workspace_timeout_track/<execution_id>/`.

When real observation flags are disabled, carried-forward Sprint 115 timeout values remain baseline evidence only. They are not marked as new Sprint 116 actual observations.
