3. ACTION BEHAVIOR

Action handling should reuse existing logic.

Acknowledge:
- mark inbox item Acknowledged.
- no reconsideration.

Defer:
- mark Deferred.
- no reconsideration.

Dismiss:
- mark Dismissed.
- no reconsideration.

ConvertToWatchlist:
- mark ConvertedToWatchlist.
- create WatchlistCandidate.
- no order.
- no position.

RequestMoreEvidence:
- mark ConvertedToFeedback.
- create OwnerFeedback EvidenceRequest.
- may open reconsideration session.
- EvidenceRegimeAI should respond.

RequestReconsideration:
- mark ReconsiderationRequested.
- create OwnerFeedback ReconsiderationRequest.
- open reconsideration session.
- chairman reconsideration decision created.
- Risk Governor still checks.

AddComment:
- create OwnerFeedback Comment.
- if targetless, log as general paper-only owner comment.
- no committee required unless explicitly paired with ReconsiderationRequest.
